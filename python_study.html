Prime Number

def isPrime(n):
    if n <= 1:
        return False
    for i in range(2, int(n**0.5)+1):
        if n % i == 0:
            return False
    return True
Examples: 2, 3, 5, 7, 11, 13

Factorial

# 5! = 5×4×3×2×1 = 120

def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n-1)

print(factorial(5))  # 120

Armstrong Number

# 153 → 1³ + 5³ + 3³ = 153 ✓

n = 153
digits = [int(d) for d in str(n)]
total  = sum(d**len(digits) for d in digits)
print(total == n)  # True

Perfect Number

# 6 → factors: 1+2+3 = 6 ✓

n = 6
s = sum(i for i in range(1, n) if n % i == 0)
print(s == n)  # True

📊 Sorting Algorithms

Bubble Sort

Compare adjacent elements and swap if out of order. Repeat until sorted.

for i in range(len(arr)):
    for j in range(0, len(arr)-i-1):
        if arr[j] > arr[j+1]:
            arr[j], arr[j+1] = arr[j+1], arr[j]
⏱ O(n²)

Selection Sort

Find the minimum element and place it at the front. Repeat for remaining array.

⏱ O(n²)

Insertion Sort

Pick each element and insert it into the correct position in the sorted portion.

⏱ O(n²) · Best: O(n)

Merge Sort

Divide and Conquer — split array into halves, sort each half, then merge.

def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid   = len(arr) // 2
    left  = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
⏱ O(n log n)

Quick Sort

Choose a pivot. Place elements smaller than pivot to its left, larger to its right. Recurse.

def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr)//2]
    left  = [x for x in arr if x < pivot]
    mid   = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + mid + quicksort(right)
⏱ O(n log n) avg

Complexity Summary

Bubble: O(n²) Selection: O(n²) Merge: O(n log n) Quick: O(n log n)
